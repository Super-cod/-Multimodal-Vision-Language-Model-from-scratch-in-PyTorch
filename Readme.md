# Vision Transformer (ViT) from Scratch

A Vision Transformer (ViT) implemented from scratch using **PyTorch**, as a personal deep learning project to explore transformer-based computer vision.

## About the Project

This project focuses on implementing a Vision Transformer from scratch rather than relying on pretrained models. It helped me understand the core architecture and the fundamentals of applying transformers to image classification.

## Features

* Vision Transformer architecture implemented from scratch.
* Built using PyTorch.
* Designed for image classification tasks.
* Supports training and fine-tuning.
* Provides a foundation for experimenting with transformer architectures.

## Model Weights

The trained model weights are not included in this repository, as they were generated for my personal use.

However, you can train the model from scratch or fine-tune it on your own dataset.
